# Elegibilidad

## Definición

Una regla de elegibilidad determina si un sujeto u objeto reúne las condiciones necesarias para acceder, participar, recibir o ser considerado para algo.

## Criterios

### Candidato y objeto

- ¿Quién o qué se evalúa como candidato?
- ¿Para qué acción, beneficio, proceso o estado se evalúa la elegibilidad?

### Condiciones

- ¿Qué condiciones habilitan la elegibilidad?
- ¿Qué condiciones descalifican explícitamente?
- ¿Deben cumplirse todas las condiciones de habilitación?
- ¿Existen conjuntos alternativos de condiciones suficientes?
- ¿Qué prioridad existe entre condiciones de habilitación y descalificación?

### Evidencia

- ¿Qué datos o evidencia se requieren para evaluar cada condición?
- ¿Qué fuente proporciona la evidencia?
- ¿Qué debe ocurrir cuando una evidencia está ausente?
- ¿Qué debe ocurrir cuando una evidencia está pendiente?
- ¿Puede existir un resultado indeterminado distinto de no elegible?

### Vigencia

- ¿Cuándo comienza a ser válida la elegibilidad?
- ¿Cuándo expira?
- ¿Qué eventos obligan a reevaluarla?
- ¿Qué condiciones hacen perder una elegibilidad adquirida?

### Resultado

- ¿El resultado debe indicar únicamente elegible o no elegible?
- ¿Debe incluir las razones que determinan el resultado?
- ¿Las razones deben tener códigos estables para poder verificarlas?
