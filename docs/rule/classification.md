# Clasificación

## Definición

Una regla de clasificación asigna una categoría, tipo, nivel o grupo a un sujeto u objeto según determinadas condiciones.

## Criterios

### Objeto

- ¿Qué entidad o valor se clasifica?
- ¿Qué datos se utilizan para clasificarlo?

### Categorías

- ¿Cuál es el conjunto posible de categorías?
- ¿La clasificación produce exactamente una categoría?
- ¿Puede producir varias categorías?
- ¿Puede no producir ninguna categoría?
- ¿Las categorías son mutuamente excluyentes?
- ¿El conjunto de categorías cubre todos los casos posibles?
- ¿Existe una categoría predeterminada o de estado sin clasificar?

### Condiciones

- ¿Qué condiciones determinan cada categoría?
- ¿Qué ocurre en los valores frontera entre categorías?
- ¿Qué debe ocurrir cuando faltan datos necesarios para clasificar?
- ¿Cómo se resuelve un caso que coincide con varias categorías?
- ¿Existe prioridad entre categorías?

### Vigencia y cambio

- ¿La clasificación depende de una versión de reglas?
- ¿La clasificación depende de una fecha de vigencia?
- ¿Qué eventos obligan a reclasificar?
- ¿Debe conservarse la clasificación anterior para trazabilidad?
