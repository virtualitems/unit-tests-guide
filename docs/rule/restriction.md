# Restricción

## Definición

Una regla de restricción establece límites sobre lo que puede ocurrir, existir, realizarse o considerarse permitido dentro de determinadas condiciones.

## Criterios

### Alcance

- ¿Qué sujeto, recurso, estado, acción o valor está restringido?
- ¿En qué contexto se aplica la restricción?
- ¿La restricción aplica por sujeto, recurso, evento, ventana temporal o una combinación de estos elementos?

### Límite

- ¿La restricción prohíbe completamente una acción o estado?
- ¿La restricción limita una cantidad?
- ¿La restricción limita una frecuencia?
- ¿La restricción limita una duración?
- ¿La restricción limita un alcance?
- ¿Cuál es el límite exacto cuando la restricción es cuantitativa?
- ¿El límite es inclusivo o exclusivo?

### Condiciones y vigencia

- ¿Qué condiciones activan la restricción?
- ¿Cuándo comienza a estar vigente?
- ¿Cuándo deja de estar vigente?
- ¿Qué datos o hechos deben existir para evaluar la restricción?

### Excepciones y conflictos

- ¿Qué excepciones existen?
- ¿Qué sujeto, condición o regla puede activar una excepción?
- ¿Cómo se resuelve un conflicto entre una restricción y una excepción?
- ¿Cómo se resuelve un conflicto entre varias restricciones aplicables?
- ¿Qué debe ocurrir cuando falta información necesaria para evaluar la restricción?

### Incumplimiento

- ¿Qué resultado observable produce una infracción?
- ¿La operación se bloquea completamente?
- ¿La operación se limita al máximo permitido?
- ¿La operación queda pendiente para otro momento?
- ¿Debe exponerse una razón o código que identifique la restricción aplicada?
