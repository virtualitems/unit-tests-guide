# Umbral

## Definición

Un umbral es una regla que utiliza uno o más valores de referencia para establecer fronteras, rangos o puntos a partir de los cuales cambia una condición.

## Criterios

### Valor de referencia

- ¿Qué valor o conjunto de valores define el umbral?

### Comparación

- ¿Qué comparación determina si el umbral se cumple?

### Resultado

- ¿Qué condición se establece cuando el umbral se cumple?
- ¿Qué condición se establece cuando el umbral no se cumple?
