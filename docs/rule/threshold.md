# Umbral

## Definición

Un umbral es una regla que utiliza uno o más valores de referencia para establecer fronteras, rangos o puntos a partir de los cuales cambia una condición.

## Criterios

### Valor de referencia

- ¿Qué valor o conjunto de valores define el umbral?

### Comparación

- ¿Con qué relación se compara?

### Resultado

- ¿Qué ocurre cuando se alcanza o supera el umbral?
- ¿Qué ocurre cuando no se alcanza?
