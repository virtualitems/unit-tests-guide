# Desasignación

## Definición

Una desasignación es una operación que elimina una relación de asignación existente entre elementos.

## Criterios

### Elemento

- ¿Qué relación o asignación puede deshacerse?

### Origen

- ¿Qué elemento o conjunto deja de estar asociado?

### Condiciones

- ¿Qué condiciones deben cumplirse para realizar la desasignación?

### Resultado

- ¿Qué relación queda eliminada?
- ¿Qué debe permanecer sin cambios?
