# Desasignación

## Definición

Una desasignación es una operación que elimina una relación de asignación existente entre elementos.

## Criterios

### Asignado

- ¿Qué elemento deja de estar asignado?

### Receptor

- ¿De quién o de qué deja de estar asignado?

### Relación

- ¿Qué relación de asignación debe eliminarse?

### Condiciones

- ¿Qué condiciones deben cumplirse para realizar la desasignación?

### Resultado

- ¿Qué otras relaciones de asignación deben conservarse?
