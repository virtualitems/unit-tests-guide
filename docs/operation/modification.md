# Modificación

## Definición

Una modificación es una operación que cambia uno o más aspectos de un elemento existente conservando su continuidad como elemento.

## Criterios

### Modificado

- ¿Qué elemento se modifica?

### Cambio

- ¿Qué dato, propiedad o relación puede cambiar?

### Condiciones

- ¿Qué condiciones deben cumplirse para realizar la modificación?

### Resultado

- ¿Qué valor o estado debe tener aquello que se modificó?
- ¿Qué datos, propiedades o relaciones deben conservarse?
