# Proceso

## Definición

Un proceso es una operación compuesta por acciones relacionadas que se ejecutan para producir un resultado dentro de un contexto determinado.

## Criterios

### Entrada

- ¿Qué información o recursos entran al proceso?

### Secuencia

- ¿Qué acciones o etapas lo componen?

### Condiciones

- ¿Qué condiciones deben cumplirse para ejecutar el proceso?

### Resultado

- ¿Qué resultado debe producirse?
- ¿Qué debe mantenerse sin cambios?
