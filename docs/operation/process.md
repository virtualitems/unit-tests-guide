# Proceso

## Definición

Un proceso es una operación compuesta por una secuencia de acciones relacionadas que se ejecutan para producir un resultado.

## Criterios

### Entrada

- ¿Qué datos o recursos necesita el proceso para comenzar?

### Secuencia

- ¿Qué acciones o etapas componen el proceso?
- ¿En qué orden deben ejecutarse?

### Condiciones

- ¿Qué condiciones deben cumplirse para iniciar el proceso?
- ¿Qué condiciones deben cumplirse para continuar entre sus etapas?

### Resultado

- ¿Qué resultado determina que el proceso se completó?
