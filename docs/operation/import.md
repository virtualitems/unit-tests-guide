# Importación

## Definición

Una importación es una operación que incorpora información proveniente de un contexto externo.

## Criterios

### Origen

- ¿De qué contexto externo proviene la información?

### Destino

- ¿Dónde debe incorporarse la información?

### Condiciones

- ¿Qué condiciones deben cumplirse para realizar la importación?

### Resultado

- ¿Qué información debe quedar incorporada?
- ¿Qué debe ocurrir con la información previa?
