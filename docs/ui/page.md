# Página

## Definición

Una página representa una vista navegable con contenido, estructura, estado y metadatos asociados a una ubicación del producto.

## Criterios

### Identidad y navegación

- ¿Qué ruta o estado navegable identifica la página?
- ¿Cuál es el título único y descriptivo de la página?
- ¿Qué debe ocurrir al usar las acciones Atrás y Adelante del navegador?
- En una navegación sin recarga completa, ¿cómo se actualizan la URL, el título y el historial?
- Después de una navegación sin recarga completa, ¿dónde queda el foco?
- ¿Cómo se anuncia la nueva vista a tecnologías de asistencia?

### Estructura

- ¿Cuál es el idioma principal de la página?
- ¿Qué cambios de idioma deben marcarse dentro del contenido?
- ¿Cuál es la dirección principal del texto?
- ¿Qué jerarquía de encabezados representa la estructura del contenido?
- ¿Existe un único contenido principal identificable?
- ¿Existe un mecanismo para saltar bloques repetidos de navegación?

### Estados

- ¿Qué se muestra durante la carga inicial?
- ¿Qué se muestra durante cargas posteriores de contenido?
- ¿Qué se muestra cuando no existen datos?
- ¿Qué se muestra cuando la ruta no existe?
- ¿Qué se muestra cuando ocurre un error?
- ¿Qué se muestra cuando el usuario no está autorizado?

### Metadatos

- ¿Qué descripción o metadata del documento forma parte del contrato?
- ¿Existe una URL canónica?
- ¿Qué directiva `robots` corresponde a la página cuando es necesaria?
- ¿Qué metadatos para compartir en redes forman parte del producto?

### Adaptación y preferencias

- ¿La página conserva información y funcionalidad al aumentar zoom o tamaño de texto?
- ¿Existe contenido que requiera una orientación específica de pantalla?
- Si existe, ¿qué requisito funcional justifica esa orientación?
- ¿Qué animaciones o transiciones deben reducirse cuando el usuario solicita menos movimiento?
